# 🌦 Weather-Data-Analysis (Interactive Dashboard creation using PowerBI Desktop)
## 🎯 Project Objective
The objective of this project is to design an interactive Power BI dashboard that consumes live weather data from Weather API sources and transforms it into meaningful insights for monitoring forecasts, air quality, and key atmospheric conditions across multiple states.

## 🔗 Data Source
The data used in this dashboard is fetched directly from Weather API platforms using the **Web (URL) connector** in Power BI.
**Note:** The project consumes live weather data directly from Weather APIs using Power BI Web connectors, hence no static dataset is stored in the repository.

## 📊 Dashboard Features
- Current temperature & weather conditions  
- 7-day weather forecast trend analysis  
- Humidity, wind speed, pressure & visibility  
- Sunrise & sunset timings  
- Air Quality Index (AQI) with pollutant breakdown  
- Chance of rain (day-wise)  
- Multi-states weather insights

## 🛠 Tools & Technologies
- Power BI Desktop  
- Web (URL) Connector  
- Power Query (JSON data transformation)  
- DAX Measures  
- Data Modeling  
- Dashboard UI/UX Design

## Dashboard Explanation
The Weather Analytics Dashboard provides a complete overview of current and forecasted weather conditions.

### Dashboard Sections
1. Current Weather Summary  
2. Weekly Forecast Trends  
3. Atmospheric Conditions  
4. Air Quality Index (AQI)  
5. Rain Probability Analysis

### KPIs Used
- Temperature (°C)
- Humidity (%)
- Wind Speed (Kph)
- Visibility (Km)
- AQI Level

The dashboard is designed with a clean dark theme for better readability and user experience.
